# socket-chat

Projet Ingénierie des Réseaux  
M1 MIAGE 2025 - 2026

## Compilation

```bash
gcc Client.c -o client
gcc Serveur.c -o serveur
```

## Utilisation

Démarrer le serveur :
```bash
./serveur
```

Démarrer le client :
```bash
./client
```

Envoyer un message du client au Serveur:
```bash
usage : client <adresse-serveur> <message-a-transmettre>: Success
```
